## Description
`spec/examples/valid/03_generic_functions_and_literals.lane` is valid under the language specification, but the current implementation rejects the annotated binding:

```lane
let f : (Int) -> Int = fn(x) {
  x
}
```

The diagnostic is `cannot_infer function literal parameter`. The specification permits function literal parameters to omit type annotations when an immediately surrounding direct context provides a function type.

## Design
Teach bidirectional local type checking to use an expected ordinary function type when checking a function literal. The expected parameter types should be pushed into the literal's parameters, and the function body should be checked against the expected result type.

This must remain local and direct-context-only. Do not infer parameter types from later calls or non-local use sites.
