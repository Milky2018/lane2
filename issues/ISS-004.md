# ISS-004: Bind pattern variables before lowering match arm bodies to Buslane

## Description
Running several specification-valid examples through `lane run --entry` aborts during Lane-to-Buslane lowering with `unknown Buslane value id`.

Observed failures:

```sh
moon run lane-tools/lane -- run spec/examples/valid/02_struct_enum_match.lane --entry origin --stdlib lane-std
moon run lane-tools/lane -- run spec/examples/valid/02_struct_enum_match.lane --entry chosen --stdlib lane-std
moon run lane-tools/lane -- run spec/examples/valid/13_existential_structs.lane --entry packed_int --stdlib lane-std
moon run lane-tools/lane -- run spec/examples/valid/14_existential_enums.lane --entry packed_int --stdlib lane-std
```

The stack points to `BuslaneLowerer::value_id` from `lower_match_arm` or struct/variant payload lowering. The immediate cause is that match arm bodies can reference pattern binders before those binders have been defined in the Buslane lowering value map.

## Design
Refactor Buslane pattern lowering so pattern binders are installed before the arm body is lowered. The lowering must preserve Buslane's one-level alternative shape and still correctly lower nested source patterns into nested Buslane matches or lets.

The fix should avoid using `abort("unknown Buslane value id")` as control flow. If an internal invariant is violated, diagnostics or a structured lowering error should eventually replace raw aborts, but this issue's primary goal is correct binder ordering.

## Acceptance Criteria
- [ ] `lane run spec/examples/valid/02_struct_enum_match.lane --entry origin` no longer aborts with `unknown Buslane value id`.
- [ ] `lane run spec/examples/valid/02_struct_enum_match.lane --entry chosen` no longer aborts with `unknown Buslane value id`.
- [ ] Existential struct and enum examples no longer hit `unknown Buslane value id` during Buslane lowering.
- [ ] A regression test covers a match arm body that references an enum payload binder.
- [ ] A regression test covers a struct pattern body that references a field binder or opened hidden witness payload.
