# Lane2

This repository is archived.

Active development has moved to the `lanelang` repositories:

- [`lanelang/lane`](https://github.com/lanelang/lane): compiler modules, Buslane, command-line tools, LSP, and executable examples.
- [`lanelang/spec`](https://github.com/lanelang/spec): the formal language specification.
- [`lanelang/stdlib`](https://github.com/lanelang/stdlib): the standard library sources.
- [`lanelang/lane_vscode`](https://github.com/lanelang/lane_vscode): the VS Code extension.

This repository is kept only as historical project context.
